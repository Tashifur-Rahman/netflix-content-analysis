# Netflix Content Library Analysis

**Project Description**

An exploratory data analysis (EDA) project investigating Netflix's content catalog using Python, Pandas, Matplotlib, and Seaborn. The project explores content types, country-wise distribution, genre patterns, content ratings, release trends, and the distribution of movie runtimes and TV show seasons.

The analysis includes data cleaning, missing-value assessment, feature engineering, and data visualization to uncover patterns in Netflix's content library and communicate findings through a structured Google Colab notebook.
